# Backlog

Everything this project might do next, in one place. `build` reads this to recommend what to work on, and adds to it whenever something is noted for later. You can edit it too: move lines between sections to change the order, or add an idea on a new line. `build` will tidy it up and give it an id.

Bugs don't go here. If something is broken, type `build` and describe it.

Item format: `- **I001** · type · size · title`, then optional indented `Why:`, `From:`, `Notes:`, `Blocked by:`, `Due:` lines.
Types: feature · change · upgrade · security · design · maintenance · idea. Sizes: S (under an hour) · M (a session) · L (several: split before starting) · ? (unknown).
